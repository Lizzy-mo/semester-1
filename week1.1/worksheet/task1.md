# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists all the files in the directory |
|     cd directory_name       | shows the name of the directoy youre currently in |
|     cd ..                   | moves you up one directory level |
|     cd -                    | moves you into the directory you type |
|     mkdir directory_name    | makes a new empty directory called 'directory_name'|
|     touch filename          | creates a new file called 'filename'|
|     git status              | shows the current state of your Git working directory and staging area |
|     git add -A              | tells Git that youve done work youre wanting to save (A indicates all the work) |
|     git commit -m ""        | essentially creates a save point that that batch of chnages will be saved under |
|     git push                | sends all the chnages to the github server where theyre permanentley stored |
|     git pull                | Updates local branch with commits from the remote server, and updates all remote tracking branches |
